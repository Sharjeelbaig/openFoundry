# Security

If you find a vulnerability in openFoundry, report it privately instead of opening a
public issue.

- Email: eng.sharjeel.baig@gmail.com
- Include the version, the platform, steps to reproduce, and what you expected.
- You will get an acknowledgement within three business days.

Supported versions: the latest release. Older releases may be asked to upgrade before a
fix is provided.

Please do not include secrets, tokens, workspace data or personal documents in a report.
