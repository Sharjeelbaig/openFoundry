Deployments that behave like deployments

Foundry puts three ideas into one label. openFoundry keeps them apart, so the parts that can work on one computer really work.
01

Serving mode

Standard and Developer meter tokens per minute and return 429 when the limit is reached. Provisioned reserves slots and queues the rest. Batch takes asynchronous jobs only. Instant answers from the local runtime.
02

Scope

Global can use any online runtime node. Data Zone uses nodes tagged for a zone. Region pins one node. Device is this computer. Routing is real. The data residency guarantee is the only simulated part.
03

Section

Serverless, Managed compute or Adapter. This is the Build > Models tab that lists the deployment.

Install the desktop app

A native window, a bundled Node runtime and the same workspace. Nothing else to install.
1
Download the DMGThe file is 57 MB. Apple silicon only.
Download for macOS
2
Move it to ApplicationsOpen the DMG, then drag openFoundry to the Applications folder.
3
Open it the first timeThe build is ad-hoc signed and not notarized, so macOS asks for confirmation. Right-click the app, choose Open, then confirm. On macOS 15 and later, use System Settings, Privacy & Security, Open Anyway.
