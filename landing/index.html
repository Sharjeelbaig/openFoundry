A look around

Deployments that behave like deployments

Foundry puts three ideas into one label. openFoundry keeps them apart, so the parts that can work on one computer really work.

Serving mode

Standard and Developer meter tokens per minute and return 429 when the limit is reached. Provisioned reserves slots and queues the rest. Batch takes asynchronous jobs only. Instant answers from the local runtime.

Scope

Global can use any online runtime node. Data Zone uses nodes tagged for a zone. Region pins one node. Device is this computer. Routing is real. The data residency guarantee is the only simulated part.

Section

Serverless, Managed compute or Adapter. This is the Build > Models tab that lists the deployment.

Install the desktop app

A native window, a bundled Node runtime and the same workspace. macOS, Windows and Linux betas come from the same source.
1
Download the installerThe macOS DMG is 57 MB for Apple silicon, the Windows installer is 35 MB for x64, and the Debian package is 64 MB for x64.
Download for macOSDownload for WindowsDownload for Linux
2
Install itOn macOS, open the DMG and drag openFoundry to Applications. On Windows, run the setup file and finish the installer. It adds a Start menu shortcut and the openFoundry command line. On Debian or Ubuntu, install the package with sudo apt install ./openFoundry_0.4.4_amd64.deb.
3
Open it the first timeNone of the builds is code signed yet. macOS asks for confirmation: right-click the app, choose Open, then confirm, or use System Settings, Privacy & Security, Open Anyway. On Windows, SmartScreen shows a warning: choose More info, then Run anyway. On Linux, install the .deb with apt or your package manager.
4
Check the downloadCompare the SHA-256 in the card with the file you downloaded.
