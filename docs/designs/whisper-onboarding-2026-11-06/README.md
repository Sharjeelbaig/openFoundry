# Whisper onboarding — 2026-11-06

The Speech page at `/build/speech` now performs real whisper.cpp onboarding:

- checks for a `whisper-cli` / `whisper-cpp` binary on `PATH` or
  `WHISPER_CPP_BIN`;
- checks for a ggml model in `~/.cache/whisper` or `WHISPER_MODEL`;
- installs the Homebrew formula `whisper.cpp` when the operator clicks
  **Install whisper.cpp**;
- downloads the selected ggml model into `~/.cache/whisper` when the operator
  clicks **Download model**;
- only reports STT available when both binary and model exist.

The helper lives in `src/lib/whisper.ts`; the page calls
`POST /api/speech/setup` with `{ "action": "install" | "download", "model": ... }`.

## Real audio through the Speech MCP tool

`whisper-sample.wav` was generated by the local TTS endpoint with the text:

> The quick brown fox jumps over the lazy dog. The vault code is 4417.

That WAV was base64-encoded and sent to `POST /api/speech/mcp` as
`transcribe_audio` with a bearer token from `/api/speech/mcp/token`.

`speech-mcp-transcribe.json`:

```json
{
  "content": [{
    "type": "text",
    "text": "The quick brown fox jumps over the lazy dog.\nThe vault code is 4417."
  }],
  "structuredContent": {
    "text": "The quick brown fox jumps over the lazy dog.\nThe vault code is 4417.",
    "engine": "whisper.cpp"
  }
}
```

The transcript matches the spoken text exactly.
